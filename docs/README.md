# b2b-media

Ausliefer-Repo für die LinkedIn-Serie „B2B Integration". GitHub Pages bedient
diesen Ordner; Buffer holt PDF und Vorschaubild von hier, wenn ein Beitrag
veröffentlicht wird.

Am 14.09.2026 geleert. Die erste Staffel — 140 Karussells plus 280 Dateien aus
der Zeit vor der kanonischen Benennung — wurde entfernt. Bereits veröffentlichte
LinkedIn-Beiträge sind davon nicht betroffen: LinkedIn übernimmt das Dokument
beim Veröffentlichen in den eigenen Bestand, die Adresse hier ist nur die
Quelle, aus der Buffer es einmal geholt hat.

Alles Entfernte steht in der Git-Historie vor diesem Commit.

Neue Beiträge landen wieder unter `docs/topic-NN/`, gespiegelt von
`linkedin deploy b2b --execute`.
